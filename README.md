# Online Shopping – Django E-commerce

A Django-based e-commerce web application where customers can browse products by category, create an account, manage a shopping cart and place orders with delivery details. Checkout checks product stock and provides an order confirmation.

## Features
- Product browsing by category
- User account registration and login
- Shopping cart management
- Delivery details during checkout
- Stock validation during checkout
- Order confirmation

## Getting Started
1. Clone: `git clone https://github.com/Lokeshkumardulla/Online-Shopping.git`
2. Extract the included `django32 (2).zip` archive.
3. Open the extracted Django project folder in a terminal.
4. Create a virtual environment: `python -m venv .venv`
5. Activate it (PowerShell: `.venv\\Scripts\\Activate.ps1`; macOS/Linux: `source .venv/bin/activate`).
6. Install dependencies using the project's `requirements.txt`, if provided: `pip install -r requirements.txt`.
7. Configure database settings locally, then run `python manage.py migrate` and `python manage.py runserver`.
8. Visit `http://127.0.0.1:8000/`.

> Configure credentials and secret keys locally. Never commit passwords or secrets.
