# Online Shopping Website

A Django-based e-commerce application where customers can browse products, create an account, manage a shopping cart, and place orders with delivery details. The project description also includes stock checks during checkout and order confirmation.

## Main workflow

1. Browse products and categories.
2. Register or sign in.
3. Add products to the shopping cart.
4. Provide delivery details and place an order.
5. Receive an order confirmation.

## Technology

- Python
- Django
- HTML and CSS
- Database configuration depends on the supplied project settings.

## Getting started

The repository includes the project archive `django32 (2).zip`.

1. Clone the repository:
   ```bash
   git clone https://github.com/Lokeshkumardulla/Online-Shopping.git
   ```
2. Extract the ZIP archive.
3. Open the extracted project folder in your editor.
4. Create and activate a Python virtual environment.
5. Install the dependencies listed in the project's requirements file.
6. Configure the database and environment settings.
7. From the directory containing `manage.py`, run:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
8. Open `http://127.0.0.1:8000/` in your browser.
